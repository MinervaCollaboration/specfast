# specfast

A Python 3 pipeline for precise radial velocities from fibre-fed echelle
spectra: extraction and Doppler forward modelling. The first instrument is
MINERVA's KiwiSpec (iodine cell); G-CLEF (Magellan, then GMT; simultaneous
comb/etalon/ThAr references, no gas cell) comes later. NEID (comb/etalon)
and LCO's NRES (simultaneous ThAr, four units, archival) are test beds for
the no-gas-cell path.

## Two stages

    raw frames --[extract]--> ExtractedSpectrum --[doppler]--> velocities
                    ^                                  ^
                    +-------- Instrument description --+

- **extract** (`specfast.extract`): raw frame plus calibration products
  (stacked bias, traces, profiles, scattered light, optional pixel flat) to
  an `ExtractedSpectrum`.
- **ExtractedSpectrum** (`specfast.products`): the contract between the
  stages. One multi-extension FITS file per exposure: per arm, flux,
  variance and a bitmask over (channel, order, pixel), per-trace
  diagnostics, a normalized header, optional wavelengths, provenance.
- **doppler** (`specfast.doppler`): a forward model of each order built
  from pure-function components (wavelength solution, LSF, star, iodine
  cell or none, continuum) on a fine ln(lambda) grid, integrated over
  pixels; then `specfast.combine` solves offsets and the error model.

The instrument (`specfast.instrument`) is data: YAML files in
`src/specfast/instruments/`. Conventions (`specfast.conventions`) match
EXOZIPPy: m/s, BJD_TDB, positive velocity = receding, relativistic
(multiplicative) composition with the barycentric correction.

See `DESIGN.md` for the architecture and `FINDINGS.md` for the evidence
behind it.

fitting engine, combination.

## Running

Each run is described by one explicit YAML file (no environment variables):

```yaml
schema_version: 1
instrument: kiwispec
paths:
  output: /path/to/output
  raw: /path/to/raw
doppler:
  wavelength: {degree: 3}
  reference: {model: iodine, atlas: iodine_atlas.fits}
```

## NRES (archival, simultaneous ThAr)

`specfast.converters.nres` reads LCO's public BANZAI-NRES products: an
`e92-1d` science file becomes an `ExtractedSpectrum` (channels `fibre0`,
`fibre1` = ThAr, `fibre2`; order index i is echelle order 52 + i), and a
master arc is optimally extracted with its lamp flat's profile, in the same
column space as the science traces. `specfast.wavecal` then fits

- ThAr line centroids (pixel-integrated Gaussians, vectorised);
- a stable wavelength model per unit and era: static reference line
  positions learned from all arcs, a low-order per-exposure perturbation
  shared by every lit fibre, one dispersion law `m*lambda = P(x, m)` and a
  static fibre offset `S_f(x, m)`, so both science fibres share one
  solution;
- the drift of any frame from its simultaneous-ThAr lines.

Velocities come from the template module (`infer` mode, no gas cell) with
those wavelengths held fixed. See `instruments/nres.yaml` for the facts and
their public sources.

## Instrument descriptions from an optical design

`specfast-zemax2instrument` (package `specfast.optics`) reads a Zemax
design (`.zar` archive or `.zmx` lens file), traces it (3-D sequential ray
trace with Zemax coordinate-break, grating and multi-configuration rules)
and writes an instrument YAML: per arm, the echelle orders on the detector,
their wavelength ranges, detector format, resolving power, order spacing
and slit pitch. Facts the design lacks (names, channel roles, gain, read
noise, site, pixel size) come from an overrides YAML; encrypted black boxes
are never decrypted, and need a stand-in in the parameters YAML.

```sh
specfast-zemax2instrument design.zar --params trace.yaml \
    --overrides facts.yaml --out instrument.yaml [--echellogram e.npz]
```

Design files, stand-in parameters derived from them and the echellogram
belong to the design's owner: keep them out of this repository. Only the
derived description is committed. See `python -m specfast.optics.cli -h`.

## Tests

```sh
python3.12 -m venv venv && . venv/bin/activate
pip install --upgrade 'pip>=25.1'
pip install -e . --group dev
pre-commit install          # ruff check + ruff format on commit
pytest -n auto              # CI: .github/workflows/tests.yml, gate check `test`
```

`tests/test_injection.py` is the acceptance test: velocities injected into
spectra generated by the forward model are recovered to better than 0.1% of
the injected amplitude without noise, with unit-variance pulls with noise.
