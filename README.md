# specfast

A Python 3 pipeline for precise radial velocities from fibre-fed echelle
spectra: extraction and Doppler forward modelling. The first instrument is
MINERVA's KiwiSpec (iodine cell); G-CLEF (Magellan, then GMT; simultaneous
comb/etalon/ThAr references, no gas cell) comes later.

## Two stages

    raw frames --[extract]--> ExtractedSpectrum --[doppler]--> velocities
                    ^                                  ^
                    +-------- Instrument description --+

- **extract** (`specfast.extract`): raw frame plus calibration products
  (stacked bias, traces, profiles, scattered light, optional pixel flat) to
  an `ExtractedSpectrum`.
- **ExtractedSpectrum** (`specfast.products`): the contract between the
  stages. One multi-extension FITS file per exposure: per arm, flux,
  variance and a bitmask over (channel, order, pixel), per-trace
  diagnostics, a normalized header, optional wavelengths, provenance.
- **doppler** (`specfast.doppler`): a forward model of each order built
  from pure-function components (wavelength solution, LSF, star, iodine
  cell or none, continuum) on a fine ln(lambda) grid, integrated over
  pixels; then `specfast.combine` solves offsets and the error model.

The instrument (`specfast.instrument`) is data: YAML files in
`src/specfast/instruments/`. Conventions (`specfast.conventions`) match
EXOZIPPy: m/s, BJD_TDB, positive velocity = receding, relativistic
(multiplicative) composition with the barycentric correction.

See `DESIGN.md` for the architecture and `FINDINGS.md` for the evidence
behind it.

## Status

Skeleton (2026-11). Working and tested: conventions, run config, provenance,
instrument descriptions (KiwiSpec provisional; G-CLEF placeholders), the
`ExtractedSpectrum` FITS format, and the Doppler forward model with its
injection-recovery tests. Interfaces only: extraction, the multi-block
fitting engine, combination.

## Running

Each run is described by one explicit YAML file (no environment variables):

```yaml
schema_version: 1
instrument: kiwispec
paths:
  output: /path/to/output
  raw: /path/to/raw
doppler:
  wavelength: {degree: 3}
  reference: {model: iodine, atlas: iodine_atlas.fits}
```

## Tests

```sh
python -m venv venv && . venv/bin/activate
pip install -e '.[dev]'
ruff check .
pytest
```

`tests/test_injection.py` is the acceptance test: velocities injected into
spectra generated by the forward model are recovered to better than 0.1% of
the injected amplitude without noise, with unit-variance pulls with noise.
